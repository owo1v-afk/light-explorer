# проводник — легкий и быстрый

красно-белый, минимализм, шрифт roboto (sans-serif), без капса, без смайликов, только svg иконки, без обводок и теней.

возможности:
- список файлов, папки, быстрое открытие
- открыть файлы до 3 гб постранично: txt, java, csv, svg, py, go, rs, cpp, c и другие
- редактирование текстовых файлов до 2 мб
- pdf, картинки, svg превью, apk инфо + установка
- zip: сжать, посмотреть, распаковать. rar: посмотреть, распаковать
- поиск по имени, быстрый, в фоне
- создать файл / папку, переименовать, копировать, переместить, удалить, выбрать все
- анализ: что занимает больше всего памяти, в папке и в хранилище

сборка:
- локально: gradle assembleDebug
- через actions: вкладка actions -> build apk -> артефакт explorer-debug
